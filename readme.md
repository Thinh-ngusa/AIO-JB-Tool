# AIO JB Tool

A lightweight jailbreak utility for A11 and below devices.

## Installation

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/Thinh-ngusa/AIO-JB-Tool/main/install.sh)"
```

After installation, run anytime with:

```bash
aiojb
```

## Features

- Device detection
- Jailbreak eligibility
- palera1n integration
- Dopamine bootstrap
- DFU / Recovery utilities
- Colored terminal UI

## Supported devices

- iPhone 5s → iPhone X
- A11 and below

## Requirements

- macOS
- palera1n
- libimobiledevice
- Python 3
