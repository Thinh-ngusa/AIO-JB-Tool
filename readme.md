# AIO JB Tool

A lightweight jailbreak utility for A11 and below devices.

## Features

- Device detection
- Jailbreak eligibility
- palera1n integration
- Dopamine bootstrap
- DFU / Recovery utilities
- Colored terminal UI

## Supported devices

- iPhone 5s → iPhone X
- A11 and below

## Requirements

- macOS
- palera1n
- libimobiledevice
- Python 3
